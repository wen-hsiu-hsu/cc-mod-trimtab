# open-items

[English](open-items.md) | 繁體中文 · [所有 mod](../../README.zh-TW.md#mods)

把待決定的問題、未解決的 bug 與延後的項目存在 context 之外，撐過 `/clear`、compact 與新 session。輸入框上方顯示數量，按一個鍵就把項目引用回給 Claude。

| 用模型 | CLI | Desktop | 雲端 |
| --- | --- | --- | --- |
| 否 | 是（手機只有狀態列） | 是 | 否 |

## 做什麼

- **Claude 登記項目**：用 `track` 工具（種類：決定、問題、延後、bug）。延後的項目會寫出什麼時候回頭處理。與未完成項目相同或互相包含的文字不重複新增。
- **沒選的選項自動延後**：你只選部分選項時（「A＋B，C 先寫成觀察項」），沒選的自動列為延後，toast 顯示延後了哪些。下一則 prompt 前可按 `[復原延後]`（`u`）或 `/open-items undo` 取消。只解析回答結尾、或後面接問句的選項清單。
- **輸入框上方顯示計數**：按 `[開啟]`（`o`）或 `/open-items` 開面板。
- **面板**：最上面是未完成的總數，旁邊一條依種類分段的長條（待決定黃色、bug 紅色、問題青色、延後灰色）和圖例。下面每個項目都顯示全文，再一行建立時間與 branch。超過 7 天的項目變淡。用 Tab 或 ↑↓ 在項目之間移動；Esc 關閉。
  - `g` 切換分組：依種類（預設：待決定、bug、問題、延後，每組用同色的線框起來）、不分組（每項寫種類）、依 branch（目前的 branch 排第一）。
  - 有其他組時，延後那組預設收起，`m` 展開或收起。
  - `s` 切換舊到新、新到舊。
  - 動作鍵和提示列固定在面板最下面（面板停靠在側邊時）。
  - 按鍵作用在停著的那一項：`d` 完成、`x` 不做、`q` 引用到輸入框。關掉的項目劃線留在原位，切換清單或重開面板才移走；再按一次同一個鍵就恢復。
  - `v` 切到這個 repo 最近 7 天完成的項目（任何 session 完成的都算），決定或不做的理由接在內文後面；`d` 重新打開，再按一次 `d` 恢復原本的結果。
  - `c` 把整份未完成清單複製成 markdown。
  - 沒有未完成的項目時，面板寫出最近 7 天完成了幾項。
  - 在面板關掉的項目會隨下一則 prompt 告知 Claude。
- **決策紀錄**：決策帶理由完成、或標為不做的項目另存到最近 300 筆的紀錄，`/open-items log [關鍵字]` 或 `track` 的 `history` 可查。
- **依 repo 跨 session 保存**：同 repo 的 worktree 共用。每次變動就合併寫入，並行的 session 不會互相覆寫。
- **載入時**：載入後的第一則 prompt 會把清單附給 Claude，toast 註明幾個在其他 branch、幾個超過 7 天。

## 指令

| 指令 | 做什麼 |
| --- | --- |
| `/open-items` | 開面板 |
| `/open-items undo` | 取消上一次的自動延後 |
| `/open-items copy` | 把清單複製成 markdown |
| `/open-items log [關鍵字]` | 查決策紀錄 |
| `/open-items stats` | 漏抓率：回答以問句結尾、沒呼叫 `track`，而你回覆超過 14 字的比例。短答（「ok」「好」）和不是你輸入的訊息不計入（逐筆記在 debug log） |

## 設定

除了 `language` 沒有其他設定（見[設定](../settings.zh-TW.md#語言)）。
